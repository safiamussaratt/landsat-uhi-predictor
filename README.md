# landsat-uhi-predictor
Machine learning pipeline for predicting Urban Heat Island intensity in Islamabad, Pakistan using Landsat-9 satellite imagery. Derives NDVI, NDBI, and NDWI spectral indices via Google Earth Engine and benchmarks five models — Linear Regression, Random Forest, Gradient Boosting, MLP, and 1D-CNN (PyTorch) — against Land Surface Temperature.
